About this site

  • Hosting: Deployed and hosted on GitHub Pages with the source code available on GitHub.
  • First published: May 11, 2023.
  • Technologies used: Developed and built using zola (v0.22.1), which is a Rust-based static site generator, with a modified version of the serene (v5.7.0) theme applied.
  • Typography: Fonts used are Karma and Work Sans.
    • These are self-hosted.
  • Icons: SVG icons sourced from Remix Icon and Font Awesome. Favicon made with Microsoft Designer.
    • These are self-hosted as well.
  • Testing: Conducted in the latest versions of:
    • Google Chrome
    • Microsoft Edge
    • Mozilla Firefox
    • Safari
    • Floorp.
  • Commenting system: Enabled by giscus which uses GitHub Discussions.
    • Will eventually migrate to remark42 or something similar...
  • Any questions or concerns about this website, or its operation, can be submitted by:
    • reaching out to me
    • creating a GitHub issue for this repo
